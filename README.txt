Bartcraft Mounts - v0.9-dev
===========================

Visual fixes from v0.8:
- Mounts overlay now covers the full spellbook page area, including native spell rows and page controls.
- Page number no longer overlaps the native page number.
- Native spells should no longer show through while the Mounts tab is open.
- Mount spell buttons use one clean icon border only.
- Mount button icon texture is cropped like Blizzard spell icons.
- Mounts layout uses a native-like two-column spellbook grid.

Install clean:
1. Exit WoW completely.
2. Extract this zip so you have:
   World of Warcraft\Interface\AddOns\BartcraftMounts\BartcraftMounts.toc
   World of Warcraft\Interface\AddOns\BartcraftMounts\BartcraftMounts.lua
3. Start WoW again.

Commands:
/bcmounts
/mountstab
/bcmounts refresh
/bcmounts reset
